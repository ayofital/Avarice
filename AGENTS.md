- Phase 0 is paper-only. Do not add signing, live swaps or credential collection.
- Runtime must work without LLM inference or paid data calls.
- Do not access MongoDB on the owner's PC, including inspection.
- Do not delete files, records, branches, state or other user data without explicit permission.
- Do not reset the virtual account or fabricate wallet metrics/trades to improve results.
- Keep local configuration, chat IDs, machine paths, credentials and runtime DBs out of Git.
- Follow RED-GREEN regression testing, preserve chain-qualified identity and report incomplete data.
- Read README.md, docs/ROADMAP.md and SKILL.md before extending scope.
- Verify exact remote commit/CI and actual delivery outcome before claiming external success.
